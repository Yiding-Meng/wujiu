# 物久：高价值物品持有成本记录 App 设计文档

**日期：** 2026-10-18  
**状态：** 已批准  
**目标平台：** Android 16 / API 36，最低 Android 8 / API 26

## 1. 产品目标

「物久」帮助用户记录自己购买过的高价值物品，并直观看到每件物品随着使用时间推移，日均成本如何下降。它是一个完全离线的个人工具，不设账号、不做云同步、不申请网络权限。

成功标准：

- 用户能在 30 秒内新增一件物品。
- 首页一眼能看到总投入、今日拥有成本和物品排行。
- 每件物品的使用天数和日均成本自动、准确更新。
- 断网时功能完全不受影响。
- 界面简洁、克制、适合长期使用。

## 4. 数据模型

### 4.1 Category

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 主键，自增 |
| name | String | 分类名称，去重 |
| iconKey | String | 内置图标标识；自定义默认 `other` |
| isBuiltIn | Boolean | 是否为内置分类 |
| createdAt | Long | 创建时间戳 |

内置分类：

- 手机 `phone`
- 电脑 `computer`
- 相机 `camera`
- 家电 `appliance`
- 交通 `transport`
- 穿戴 `wearable`
- 影音 `audio`
- 其他 `other`

### 4.2 Asset

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 主键，自增 |
| name | String | 物品名称 |
| categoryId | Long | 关联分类 |
| priceCents | Long | 购入价格，以分为单位存储 |
| purchaseDateEpochDay | Long | 购买日期，按本地日期存 `epochDay` |
| notes | String | 备注，可为空 |
| imageUri | String? | 本地持久化图片 URI，可为空 |
| inactiveDateEpochDay | Long? | 停用/出售日期；为空表示仍在使用 |
| createdAt | Long | 创建时间戳 |
| updatedAt | Long | 最后修改时间戳 |

### 4.3 计算规则

所有天数计算以设备本地时区的“今天”为准。

- 活跃物品：
  - `使用天数 = max(1, todayEpochDay - purchaseDateEpochDay + 1)`
- 停用物品：
  - `使用天数 = max(1, inactiveDateEpochDay - purchaseDateEpochDay + 1)`
- 日均成本：
  - `priceCents / 使用天数`，展示时保留两位小数
- 今日拥有成本：
  - 仅统计活跃物品，各自 `priceCents / 使用天数` 之和
- 总投入：
  - 全部未删除物品的价格之和，不因停用而扣除

购买日期不得晚于今天；停用日期不得早于购买日期，也不得晚于今天。

分类名称去除首尾空格后不能为空，且不区分大小写不能重复。

价格使用整数分存储，避免浮点误差。输入支持最多两位小数，不设人为上限。

## 5. 视觉设计

### 5.1 方向

关键词：清晰、温润、数据感、长期主义。

采用已选定的“清晰数据面板”方案：

- 米白底色与白色卡片
- 深森林绿作为主色
- 鼠尾草绿和暖沙色作为数据卡点缀
- 卡片圆角 20dp，页面边距 20dp
- 大号数字使用紧字距，突出关键数据
- 列表优先显示“物品名、分类、使用天数、日均成本”
- 不使用廉价渐变、玻璃拟态或过度阴影
- 图标使用 Material Symbols / 内置矢量图标，不用 emoji 代替图标

### 5.2 颜色

浅色：

- 背景 `#F5F6F2`
- 卡片 `#FFFFFF`
- 主色 `#1D5C45`
- 主色容器 `#DCE8E1`
- 暖色容器 `#F0DFC6`
- 主文本 `#151A17`
- 次文本 `#6F7972`
- 分隔线 `#E4E7E1`
- 危险色 `#B3261E`

深色：

- 背景 `#111613`
- 卡片 `#1A211D`
- 主色 `#8EC9AD`
- 主色容器 `#284638`
- 主文本 `#F1F4EE`
- 次文本 `#A7B0A9`
- 分隔线 `#303A33`

所有正文文字对比度至少满足 WCAG AA。颜色不作为唯一状态表达。

### 5.3 组件和布局

- 顶部：左对齐标题“我的大件”，右侧圆形新增按钮。
- 概览：两列数据卡，左侧“已为大件花费”使用暖沙色，右侧“今天的使用成本”使用鼠尾草绿。
- 筛选：横向滚动胶囊，选中项深绿填充，未选中项白底描边。
- 列表：白色圆角卡片，左侧分类色块图标，中央名称与元数据，右侧日均成本。
- 排序：默认按日均成本从高到低；可在后续版本增加排序面板，本期仅固定这一排序。
- 空状态：简洁图形、一句说明和“添加第一件物品”按钮。
- 新增表单：顶部栏含返回和保存；字段纵向排列；日期和分类使用底部弹层选择；保存按钮固定在底部安全区上方。
- 详情：顶部大图/分类图标区，关键指标横向排列，下面显示购买信息和备注；底部为次要操作区。
- 删除：使用明确的二次确认对话框，说明不可恢复。
- 动效：页面进入 180–240ms 淡入与轻微上移；列表新增使用布局动画；遵循系统“移除动画”设置。

### 5.4 字体

- 使用系统中文字体，确保可读性和安装包体积。
- 标题 26–28sp，半粗。
- 数据数字 28–36sp，半粗，紧凑字距。
- 正文 15–16sp。
- 辅助信息 12–13sp。
- 所有文本随系统字体缩放，不锁死行高截断。

## 6. 交互与状态

### 6.1 首页

- 分类胶囊点击后立即筛选，选中“全部”恢复完整列表。
- 列表项点击进入详情。
- 新增按钮进入空白新增表单。
- 无物品时，概览显示零值，并展示空状态。
- 今日成本表示“今天这一天分摊的拥有成本”，不是累计总成本。

### 6.2 新增/编辑

- 名称必填，最多 40 字。
- 价格必填，必须大于 0。
- 购买日期默认今天。
- 分类默认“其他”或上一次选择；首次使用默认“其他”。
- 备注最多 200 字。
- 图片可选，选择后复制到应用私有存储，避免外部 URI 失效。
- 图片支持裁剪为方形，限制分辨率与文件体积。
- 保存时校验；错误显示在对应字段下方。
- 返回时若有未保存修改，弹出“放弃修改？”确认。
- 编辑已有物品时，图片可替换或移除。

### 6.3 分类

- 内置分类不能删除。
- 自定义分类只有在没有物品使用时才能删除。
- 删除自定义分类前二次确认。
- 新增分类即时出现在表单选择器中。

### 6.4 停用/恢复

- 详情页可标记“已停用/已出售”，并选择日期，默认今天。
- 停用后使用天数固定，不再增长，仍计入总投入。
- 已停用物品不出现在“今日拥有成本”中。
- 可恢复为使用中，恢复后按今天继续累计。

### 6.5 删除

- 详情页提供删除入口。
- 二次确认后方可删除。
- 同时删除应用私有目录中的物品图片。
- 删除不可撤销。

## 7. 技术架构

### 7.1 技术栈

- Kotlin
- Jetpack Compose + Material 3
- Navigation Compose
- Room + KSP
- Kotlin Coroutines + Flow
- ViewModel + StateFlow
- Coil Compose 加载本地图片
- Gradle Version Catalog
- JUnit + Robolectric（计算和 ViewModel）
- Compose UI Test（核心流程）

### 7.2 模块与职责

单 app 模块，按包职责拆分：

- `data/local`：Room entities、DAO、数据库、迁移
- `data/repository`：分类与物品仓库接口及实现
- `domain/model`：领域模型
- `domain/calculation`：使用天数、日均成本、汇总计算
- `ui/home`：首页 UI、ViewModel、状态
- `ui/detail`：详情 UI、ViewModel
- `ui/editor`：新增/编辑 UI、ViewModel
- `ui/categories`：分类管理 UI、ViewModel
- `ui/components`：可复用卡片、数字、空状态、表单组件
- `ui/theme`：颜色、字体、形状、主题
- `util`：日期与金额格式化

### 7.3 数据流

`Room DAO -> Repository -> ViewModel (Flow) -> Compose UI`

- 写入通过 Repository 和 Room 事务完成。
- UI 只观察不可变状态对象。
- 计算逻辑放在纯 Kotlin 函数中，不依赖 Android 框架，便于测试。
- 首页将 `AssetWithCategory` 映射为展示模型，避免 UI 重复计算。

### 7.4 图片处理

- 使用 Android Photo Picker 选择图片，不申请宽泛存储权限。
- 读取后复制到 `filesDir/asset_images/`。
- 保存前压缩到边长约 1600px、JPEG 质量约 85。
- 替换或删除时清理旧文件。
- Coil 从 File URI 加载，并显示占位背景。

### 7.5 离线与隐私

- Manifest 不声明 `INTERNET` 权限。
- 数据只存在本机。
- 不接入统计、广告、崩溃上报 SDK。
- 不使用远程字体或远程图片。
- 卸载应用会删除所有数据，UI 需在“关于/隐私”说明中明确提示。

### 7.6 错误处理

- 数据库读写失败：显示 Snackbar，保留用户已填内容。
- 图片复制/压缩失败：提示“图片处理失败”，仍允许保存无图片物品。
- URI 失效：显示分类占位图，不阻塞详情打开。
- 日期或金额非法：表单内联错误，保存按钮不可提交。
- 分类被删除时的外键冲突：禁止删除并提示仍有关联物品。

## 8. 测试策略

### 8.1 单元测试

- 购买当天使用天数为 1。
- 购买后第 N 天使用天数正确。
- 跨月、跨年、闰年计算正确。
- 停用物品天数冻结。
- 日均成本按分计算，显示四舍五入正确。
- 今日成本只包含活跃物品。
- 总投入包含停用物品。
- 分类名称去空格与重复校验。

### 8.2 ViewModel 测试

- 首页加载空数据。
- 首页筛选分类。
- 新增表单校验与保存。
- 编辑后数据刷新。
- 停用和恢复更新首页汇总。
- 删除后列表刷新。

### 8.3 UI 测试

- 空状态到新增第一件物品。
- 新增后首页出现正确日均成本。
- 点击列表进入详情。
- 编辑价格后使用天数不变、日均成本更新。
- 停用后不再计入今日成本。
- 删除确认流程。
- 深色模式核心页面可读。

### 8.4 手工验收

- 在 API 36 模拟器验证 edge-to-edge、系统返回和字体缩放。
- 切换系统深色模式。
- 选择、替换、移除图片。
- 断网状态启动与完整流程。
- 冷启动后数据保留。
